# Introduction

ProAbono is a subscription-billing platform; API Backoffice is designed to craft end-user experiences in a few calls. The API lets you manage subscriptions programmatically — create customers, start or update subscriptions, check feature access, and calculate billing costs before committing to a change.

Before getting started, you need a ProAbono account. [Sign up here](https://via.proabono.com/Auth/Welcome) to create one.

:::warning
Calling the API from a browser exposes the API key in network requests, browser DevTools, and JavaScript bundles — visible to any user. Use a server-side proxy instead:

```
Browser → Your backend → ProAbono API Backoffice
```

Your backend holds the API key; the browser never sees it.
:::
