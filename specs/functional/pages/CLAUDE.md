# Pages

This folder contains the specifications for each documentation page of the API Backoffice documentation website.

> **No "Getting Started" section.** The shared DocApi navigation spec lists Getting Started at sidebar position 2, but this API has no such section. The sidebar goes directly from Introduction to Authentication.

> **Guides is empty for now.** The Guides section holds one page per cross-resource action documented in the ProAbonoBO shared utility. No such action is documented yet, so the section holds no page: it shows neither in the sidebar nor among the sections of the search until its first page exists.

1. [introduction.md](introduction.md) — Introduction page spec
2. [authentication.md](authentication.md) — Authentication page spec
3. [concepts.md](concepts.md) — Core Concepts and Conventions pages spec
